# CampusConnect

A React Native app designed to connect gamers on college campuses. Built with Expo and React Navigation.

## Features

- **Review Screen**: Review and rate gaming partners after playing together
- **Matching System**: Find compatible gaming partners based on tags and interests
- **Profile Management**: Customize your gaming profile with tags and interests
- **Retro Pixelated UI**: Unique 8-bit aesthetic design

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Expo CLI (`npm install -g expo-cli`)

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Run on your preferred platform:
- Press `i` for iOS simulator
- Press `a` for Android emulator
- Scan QR code with Expo Go app on your phone
